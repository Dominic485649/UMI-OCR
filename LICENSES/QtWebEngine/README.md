同版官方完整源码归档随产品保留在 source/third_party/qtwebengine-everywhere-src-6.11.2.tar.xz；SHA-256 与下载 URL 见 manifest.json。third-party-notices.zip 从该归档只读提取 LICENSE、COPYING、NOTICE 和 qt_attribution.json，保留原始路径与字节，不执行来源脚本。

此记录不声称自行重建 Qt/Chromium，也不替代各组件实际许可条件。构建和源文件恢复入口、锁定 wheel 与输入摘要随产品对应源码保留。
