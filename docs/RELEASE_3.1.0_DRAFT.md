## 识别、资源与 HTTP

- 大图先检查压缩体积和解码尺寸，再在有限预算内分块。文本框映射回原图坐标并去重排序。未完成区域或截断必须显式报告，不把有部分文字当作全文成功。
- VL 文档在推理前应用页范围，逐页回传并保留原页号。任务总预算不因进度事件无限延长。
- GUI、HTTP 与预热共享一个重型执行槽和真实模型实例。取消绑定具体执行，不应终止排在后面的任务。
- HTTP 请求冻结后端、配置和参数 schema，不通过修改 GUI 选择实现路由。新增结构化文档接口，旧分页文字 OCR 接口保留。
- 新结构化接口具备参数类型与范围校验、任务级取消、部分结果下载和任务自有资源发布。详情见 [HTTP 接口契约](http/api_document.md)。

## 内置运行时与模型边界

VL 插件只执行包内固定 llama.cpp，不再提供运行程序路径设置，不搜索 PATH，也不执行旧配置中的外部路径。监听地址固定为本机回环，端口可调。外部端口占用时明确失败，不接管或终止外部服务。

- 固定源码提交：`74bca3950054eed1795f525cb9cf06bfe796492d`。
- 本轮构建使用 CUDA Toolkit 13.4.92，保持 C++17 和非本机专用构建。
- 支持目标从 RTX 20 系及以后开始。架构产物和本机设备发现已核对，但不代表所有 GPU 和旧驱动均已实机验收。
- 主 GGUF、视觉投影和版面模型仍由用户导入。本轮不下载、不改精度、不量化或分发这些模型。
- 源码、许可、依赖来源和内容哈希随对应产品保留。组织及使用场景的许可适用性不作法律确认。
