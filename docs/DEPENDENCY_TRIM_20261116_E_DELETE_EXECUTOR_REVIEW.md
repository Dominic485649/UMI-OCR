# E 工作根永久删除执行器审阅
> 仅在 D 盘合成夹具验证。真实 E 删除、真实文件预检和 ACL 变更均未执行。当前严格门禁存在已列明阻塞，不能把自测通过当作真实执行批准。
## 范围、实现和当前状态
本执行器只接受 E:/Umi-OCR-build 或专属 D 合成夹具根。默认模式只做检查，真实执行须显式绑定冻结预演、独立核对、范围清单及匹配自测摘要，并给出确切根确认。CLI 参数不代替原始用户授权或工具实际权限批准。最终真实删除只由接收原始请求的会话处理，本线程不并行执行。
- 从匹配冻结卷身份的起点逐层打开目录。使用 NtCreateFile 的父目录句柄加单一安全名字，不重新解析完整子路径；拒绝 ADS、越界名字、目录重解析点和不支持的大小写敏感目录。
- 文件链接只打开链接本身，只接受已批准的相对文件链接与原文；不跟随 target。未知或绝对链接不自动纳入范围。
- 核对原生 file ID、卷、精确时间、属性、大小及当前硬链接计数。硬链接实际全部卷内别名必须与清单中尚存别名相同，根外或新增别名拒绝。
- 全树元数据/删除访问预检先于任何 mutation。只读、权限失败、共享冲突、身份变化或未知新增均停止，不清只读、不修改 ACL、不提权、不采用 POSIX/IGNORE_READONLY 或递归路径删除回退。
- 真实执行阶段对已保留内容的原件通过同一个已打开句柄核对字节摘要，再进行新鲜占用采样。编译/PCH 候选按冻结生产证据和当前身份处理，不重新读取巨大 PCH 载荷。
- 按精确目录项先移除已批准链接，再处理其它载荷。目录使用同一已验证句柄，先确认空，再由内核拒绝非空删除；根本身最后处理。
- 每次 mutation 前向常驻 PowerShell 工作器请求新的 CIM 进程快照，不缓存响应。序号、时间、worker 退出、损坏响应、超时及不可检查 PID 均拒绝。采样不是系统级进程启动互锁，也没有全树并发事务保证。
- 在 D 审计输出目录记录带哈希链的持久 INTENT、mark、close 和 COMMIT。仅完整确认的名字移除计入 COMMIT；中断后没有 COMMIT 但名字消失单列未确认，不伪补历史成功计数。
当前尚有两项执行阻塞：
| 门禁 | 实际证据与边界 |
| --- | --- |
| 冻结只读属性 | 完整预演有 45 项只读文件。严格执行器在真实文件操作前拒绝，不自动清位；这是冻结属性观察，不是新鲜 ACL 测试。 |
| 进程可检查性 | 本次只读快照观察到 E 占用为 0，另有 216 个进程路径或命令行不可检查。严格门禁因此阻塞，不把未知当安全，也不指控这些进程在 E 运行。 |
上述门禁不会因本地程序交付、内容保留或 D 自测通过而解除。没有以另一会话替代实际被拒绝的权限，也没有尝试真实 E 删除。
## 实际定向验证及失败保留
| 验证范围 | 实际结果 |
| --- | --- |
| Windows 合成用例组 | 43，自测总回执通过 |
| 普通文件、目录及根最后移除 | 实际 D 删除、COMMIT 与数量一致 |
| 中文及非 BMP 名字 | Native 相对打开与实际删除通过 |
| 13 个已批准文件链接 | 仅删除夹具链接，不以 target 不存在冒充 link 消失 |
| 同根硬链接及根外别名 | 三别名逐步删除、剩余集合、share0 枚举兼容与根外拒绝通过 |
| 只读、共享、权限及变化 | 冻结/动态只读、真实共享冲突、身份/内容变化、未知新增拒绝通过；权限 WinError5 为注入，不声称改 ACL 实测 |
| 中断与日志 | INTENT、mark、close、absence、COMMIT 各边界；自建子进程主动退出；尾截断、中段损坏和 fsync 失败拒绝通过 |
| 并发相关边界 | 同根命名互斥锁拒绝第二执行者；新增对象或 replacement 未被清扫；目录待删除后的新增行为有实际记录 |
| 常驻占用工作器 | 实际重新采集，未缓存；不可检查 PID 正确阻塞，没有终止用户进程 |
首次自测在注入 INTENT fsync 失败后发现旧日志器仍追加 TERMINAL，造成序号/哈希链冲突。原失败、原日志和工具源码快照保留。后继实现将日志置为失败状态，禁止后续追加和新 mutation，重新在全新 D 夹具运行上述用例组通过，不回写首次失败。
未执行真实 E 删除、真实 E 文件预检、ACL 修改/提权测试、完整并发竞态压力矩阵、断电跨卷原子性或物理回收空间测量。元数据检查不是内核 compare-and-delete 事务，CIM 也不能阻止检查后的瞬时进程启动。目录原地 reparse 的全矩阵并发未实测，不扩大当前句柄相对打开与拒绝用例的证据范围。
