# Umi-OCR CUDA OCR 插件 v3.0.2：配套版本与发布范围

> 待发布文案。当前公开发行门禁未通过，本稿不是发行完成公告。已经核验的归档仍为本地候选，不得改名冒充正式包。

本插件为 Umi-OCR 提供 PP-OCRv6_medium 离线 GPU OCR。本版与主程序产品版本同步，配合动态批量队列和文档交互更新。本轮插件代码相对公开前版仅同步产品版本，不宣称升级了识别引擎、模型或推理精度。

## 版本与安装

| 项目 | 本版范围 |
|---|---|
| 插件产品版本 | 3.0.2 |
| 主程序 Host API 兼容范围 | `>=2.7,<3.0`，不因产品版本变化而改为 API 3 |
| 平台与依赖 | Windows 10/11 x64，CUDA 12.6；依赖版本不升级 |
| 推理方式 | 独立 CUDA worker，按需加载，不静默回退 CPU |
| 模型 | 复用既有离线模型，未下载、重新派生或改变量化精度 |

请先完整解压匹配的主程序基础包，再将插件完整解压到同一应用根目录。保留 `UmiOCR-data/plugins/win32_PaddleOCRv6_CUDA/` 和 `LICENSES/plugins/win32_PaddleOCRv6_CUDA/` 的相对路径。插件许可证和对应源码不能覆盖主程序的同名记录。

需要兼容 CUDA 12.6 的 NVIDIA 显卡与驱动。运行环境由包内提供，不需要另装 Python 或系统 CUDA Toolkit。CUDA、模型或必要依赖不可用时明确报错，不以 CPU 执行冒充 GPU 成功。

`.tar.xz` 需要完整解开外层 xz 与内层 tar。建议在新目录安装主程序和插件，不覆盖运行中的旧目录。本轮未迁移旧配置、替换旧安装或清理旧产物。
