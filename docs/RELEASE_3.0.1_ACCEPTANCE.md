# v3.0.1 验收范围与发布决定

记录日期：2026-10-18。此决定仅适用于本次 v3.0.1 主程序基础包及 CUDA OCR 插件，不构成后续版本的默认豁免。

## 维护者确认

在获知发布复核结果及尚未完成的人工覆盖项后，维护者依次确认：

> HDR捕获是成功的，能否继续？

> 我觉得可以发布了

此前已批准两份 Release 文案，并授权门禁复核后的 GitHub 发布。本次后续确认按明确知悉验收范围后的发布决定记录，不再把同一人工覆盖限制当作未取得发布决定。

## 已验证与未验证范围

- 实际 HDR 捕获成功是维护者报告的结果，没有冒称自动化独立重测或采集用户桌面图像。
- 本轮实际归档中的原生 DLL 已通过合成 HDR shader 测试。纯坐标源码测试通过，不等于真实混合显示器或选区界面验收。
- 零可选后端、强制 UTF-8、真实 CUDA OCR/PDF、HTTP/命令行、界面热切换和托盘有本轮自动化记录。托盘首次 HTTP 就绪时序失败及等待就绪后的成功复测均保留。
- 混合 HDR/SDR、多屏不同 DPI、负虚拟坐标、完整视觉/选区、主窗口隐藏恢复及完整重复选区清单没有逐项取得本轮人工通过记录，继续保留为未测或未完整验证。
- 发布门禁对当前端到端验收采用 `ACCEPTED_WITH_LIMITATIONS`，不是把上述未测项目修改为 `PASS`。发布说明和制品证据必须携带该限制。

## 不受此决定豁免的项目

- 第三方许可、模型和 NVIDIA 运行库的适用条款及对应源码义务。
- 对应源码真实公开可取得、标签与提交绑定、源码快照完整性。
- 最终归档完整性、隐私过滤、覆盖安装时不改写宿主记录。
- 审计不得丢失新增硬门禁，不得把候选模式或缺失证据当作严格公开通过。

本次不更换模型、推理依赖或精度，不发布 CPU/PaddleOCR-VL 插件，不覆盖既有版本或删除历史制品。
