# Umi-OCR 3.0.2 本地候选说明

本版本用于本项目内的 Windows x64 本地交付，不创建公开标签、不推送、不发布 GitHub Release。`local-candidate` 表示尚未申请公开放行，不表示可以省略本地运行验证。

## 更新范围

- 批量文档的打开与拖入共用导入流程，运行和暂停时允许新增，异步导入请求互相隔离。
- 等待文档可拖拽排序、从队列移除，实际处理顺序和文档数、页进度同步更新。当前处理和保存中的文档受保护。
- 文件行右键提供打开原件、打开实际 OCR 产物、单件重新 OCR 和移出队列。移除不删除磁盘上的原件或结果。
- 单件重识别使用独立输出前缀，成功后才更新最近成功产物。失败或取消不覆盖旧结果。
- 加密件保留为待解密，正常件继续执行。未解决的文档不会被静默计为已识别。
- 修复忽略区域的右键绘制状态、数组通知、取消和边界处理，预览使用当前编辑区域。
- 批量 OCR 可在运行中追加图片，任务续接与输出器最终收尾分开处理。

实际验收状态见 [3.0.2 验收记录](RELEASE_3.0.2_ACCEPTANCE.md)。源码或包发生变化后，必须重新验证受影响项目，不能继承旧包的 PASS。

## 本地交付布局

```text
release/
  Umi-OCR_v3.0.2-local-candidate_Windows_x64/
  Umi-OCR_v3.0.2-local-candidate_Windows_x64.tar.xz
  Umi-OCR-Plugin_GPU-OCR_v3.0.2-local-candidate_Windows_x64_CUDA12.6.tar.xz
```

可运行目录安装 CUDA 插件。本体压缩包不含 OCR 推理后端，CUDA 插件压缩包解压到本体根目录，保留归档相对路径。

必要许可证、对应源码和来源记录保留在交付物内部。外置归档完整性、SHA-256、安装验证和当版本地验收证据放在本项目 `build/audit/3.0.2`，不把用户配置、任务数据和重复测试副本放进压缩包。

## 保持不变的边界

- Python、Qt、CUDA 和推理依赖沿用锁定输入，不通过本次修复升级依赖。
- 离线复用现有模型与派生结果，不下载新权重、不改变量化精度。
- 保留原始 Umi-OCR 署名、MIT 声明、AGPL 组合发行说明和插件独立许可材料，不新增模型或商标授权结论。
- 公开门禁和本地运行验收分别记录。当前本地交付不把公开源码、公开发行许可或人工覆盖范围改写成 PASS。
- 不继承 3.0.1 的人工接受结论，也不更改历史发布资产或回执。

## 清理和用户数据

只清理本项目经确认的旧产物和无效缓存。先验收新版，再检查占用、备份旧配置和任务临时数据，最后切换与清理。不强杀用户进程，不操作兄弟项目，不整目录清空模型、对应源码或依赖缓存。
