## 本次变化

PaddleVL 独立版本为 **3.1.4**，要求 Host API **`>=2.9,<3.0`**，本次实际验收使用宿主 API **`2.9`**。主程序和 CUDA 插件各自维护版本，不强制同版。

- 将私有 OpenCV 替换为固定源码构建的图像运行子集 `4.10.0.84+umi.coreimg.1`，保留实际图像、版面和文档消费者需要的能力，不声称提供完整 contrib API。
- 将私有 ModelScope 派生为 `1.38.1+umi.download.1`，保留 snapshot 参数、回调、异常和缓存行为，分离未使用的模型、训练、上传框架和开发命令。
- SciPy 与 scikit-learn 采用明确标记的私有运行子集。保留官方标题层级所需 KMeans、StandardScaler、实际科学计算及文档消费者闭包；派生 METADATA、RECORD 和裁切回执标识真实载荷，不把部分库冒充完整上游发行版。
- 不再把科学库的开发源码、类型与编译输入混入运行载荷。完整输入和来源材料保留在独立源码/审计材料中。
- 插件依旧自带推理依赖和 llama.cpp 服务，不借用宿主的私有数值计算库缩小体积。图片 OCR 与复杂文档解析保持共享服务生命周期。
- 不下载、量化或修改既有权重，不削减语言、精度、模型族或既有 GPU 架构。模型手动导入和官方固定来源下载功能保留，不在启动时自动下载。

- 透明 worker 观察实际捕获非空标题高度输入，确认运行到官方标题聚类路径，而非只测空输入或导入成功。
