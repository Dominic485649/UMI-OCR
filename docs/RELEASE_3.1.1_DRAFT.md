# Umi-OCR v3.1.1：模型设置与界面体验升级

> 文案审阅稿，尚未发布。公开主程序目前为 v3.0.3，因此本稿合并此后尚未公开的 3.1.0 与 3.1.1 更新，并以当前最终界面行为为准。

## 更新亮点

### OCR 设置更直观

- **模型和识别参数回到具体功能页。** 在截图 OCR、批量图片 OCR、批量文档各自的设置区即可选择识别模型并调整本类别参数，不必反复切换到全局设置。模型仍为全局共享选择，各类别参数独立保存。
- **全局设置保留共用策略。** 模型预热、自动清理、插件与设备设置集中管理；NVIDIA 设备通过异步下拉列出实际逻辑 GPU 编号和名称，失效设备不被静默替换。
- **新配置默认缩放 125%。** 保留已有合法缩放和显式主题选择，新配置默认跟随系统主题，原生标题栏与应用主题同步。
- **减少界面打扰。** 全局设置不再自动弹出“小贴士”；长说明与 URL 悬浮提示限宽、自动换行。首页“官方网站”更名为“仓库链接”，链接目标保持为本项目 GitHub 仓库。
- **版本信息更清楚。** 首页分别显示主程序和实际已安装插件的独立版本，并标注插件状态；补齐现有语言的相关界面文案和热切换。

### 大图、任务与接口

- 大图在受限解码与资源预算内分块处理，结果映射回原图坐标；未完成区域或截断明确报告，不将部分结果误报为全文成功。
- GUI、HTTP 和预热共享重型任务调度，取消与具体任务绑定，避免影响排队中的其他任务。
- HTTP 按请求冻结后端和参数，不通过改写 GUI 选择实现路由；补充结构化文档任务接口、任务取消和部分结果下载，保留原有分页文字 OCR 接口。

### 文档解析逐页查看

以下功能需要安装兼容的文档解析插件，基础程序不内置解析模型。

- 文档解析采用与批量文档一致的双栏布局，输入、原页预览、设置和结果更易查看。
- **未开始解析也能翻页。** 导入多页文档后即可浏览各页原稿，不再受限于第一页或等待整篇解析完成。
- **已完成页提前可见。** 解析过程中即可查看已经完成的页；文本、Markdown、JSON、结构块与当前页统一切换。
- 补齐 JSON 双向滚动、结构块滚动与预览区域联动；支持当前页/整篇查看，取消或失败时保留已完成结果，整篇导出继续可用。

### 运行与封装

- 详细平台、CPU 和内存信息改为后台采集，版本与路径信息可以先显示；启动观测默认关闭。
- 宿主及插件将选定的 Python 源文件分别聚合为独立的 ZIP_STORED 容器，减少散文件，不在启动时整体解包；原生库、模型和必要资源仍保持独立。
- 容器缺失、损坏或布局冲突明确报错，不静默使用旧文件。此项不等同于已证明整体启动更快。

基础包 `Umi-OCR_v3.1.1_Windows_x64.tar.xz` 不含 OCR 推理插件或模型。首次使用 OCR 须自行安装已公开、符合 Host API 与平台要求的兼容插件；本次不会创建新的 CUDA 插件下载、源码发行或标签。

## 安装与更新

1. 正常退出旧程序，将基础包完整解压到新目录。
2. 将所需的兼容插件完整解压到同一应用根目录，保留原有相对路径、许可证和对应源码材料。
3. 从 `Umi-OCR.exe` 启动。迁移旧配置前保留原件，不覆盖运行中的目录。

`.tar.xz` 包含 xz 和 tar 两层；如果解压工具先生成 `.tar`，请继续解包，直到根目录出现完整程序和 `Umi-OCR.exe`，不要只复制启动器。运行 CUDA 插件需要兼容 CUDA 12.6 的 NVIDIA 显卡和驱动，无需另装 Python 或系统 CUDA Toolkit；CUDA 不可用时明确报错，不静默回退 CPU。

- 先前 3.1.1 本地组合包已完成全新构建、归档完整性检查、三归档重新安装、真实 Qt 窗口、正常 EXE、第二实例 CLI 转发和回环后端注册检查。相关业务模块与包内源码快照逐项绑定。
- 更名候选的主程序运行载荷已验收通过；本次按用户指示整理纯本体对应源码，排除 CUDA 插件实现，最终公开包以实际源码、归档哈希、许可及针对性验收记录为准，不沿用旧包摘要冒称新包通过。
- 此前受控逐页回调验证了预览与结果交互，不等于 GPU 质量/性能矩阵通过。既有本地真实推理结果只适用于其实际输入、硬件和组件，不作为本次 CUDA 公开发行承诺。
- **截图相关测试后续不再执行。** 完整桌面捕获、人工 HDR、混合 HDR/SDR 和多屏覆盖在本轮保留 **NOT_RUN**，按已披露的未测限制交付，不宣称 HDR 或混屏实测成功。既有坐标及 HDR shader 自动记录不等于新增截图实测。
- 密集图识别仍可能有误字及位置偏差；未对所有显卡、旧驱动、多屏或资源极限作通过承诺，也不宣称整体启动速度获得稳定提升。
- 不下载新模型、不更改权重或量化精度；第三方组件按各自许可使用，不新增模型或商标授权主张。
