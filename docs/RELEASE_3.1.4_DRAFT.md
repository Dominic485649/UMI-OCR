## 更新内容

- 新标签改为任务工作台：用途直接可读，真实组件版本与状态分开显示，提供模型／插件设置入口。
- 设置左栏标记当前分组，支持嵌套模型分组定位、无 OCR 插件时回退、键盘滚动后更新选中状态；窄窗口键盘焦点自动滚动到可见区域。
- 热切换语言时同步文字缩放；更新六份真实 QM 翻译。
- 结果历史淘汰时不再把选区静默转移到另一条记录；手动删除归还字节预算，无选区复制安全返回。
- 普通 `D` 后一次 `Ctrl+D` 不再误清空全部记录；按住自动重复和时钟后退不算双击，保留真正连续两次 `Ctrl+D` 的清空行为。
- 正确恢复 Qt QVariantList 保存的标签，按稳定页面 key 查找动态插件页，拖动跨越活动页时保持活动对象。
- 更新中英日 README、真实窗口展示、CLI／HTTP／CUDA 参数指南；45 份旧版正文移入历史区，6 张旧 UI 图退出当前展示，保留原字节与摘要。
- [深入审查与优化路线图](PROJECT_REVIEW_2026-11-08.md)区分动态复现、静态问题、待验证风险和工程建议，不宣称全项目无缺陷。
