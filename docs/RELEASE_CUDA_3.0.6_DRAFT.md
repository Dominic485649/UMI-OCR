# Umi-OCR PP-OCRv6 CUDA 插件 v3.0.6 审阅草稿

> 尚未公开发布。最终运行归档、独立源码归档及全新重装已完成；新本体组合已完成全新归档重装及实际 EXE/接口/Qt 验收，固定安装事务已提交且载荷、原有保留文件摘要一致；当次程序/文案公开发布审查尚未通过。此稿不替换任何旧版本的审查原文。

## 本次变化

CUDA 插件独立版本为 **3.0.6**。清单声明 Host API **`>=2.7,<3.0`**，本次已测试本体提供 **`2.9`**。主程序、CUDA 和 PaddleVL 独立维护版本，不以同版号代替兼容性验证。

- OpenCV 从固定源码构建图像运行子集，保留实际消费者需要的 core、imgproc、imgcodecs 和匹配 Python 绑定，不再携带未使用的视频、GUI 等模块。明确派生版本为 `4.10.0.84+umi.coreimg.1`，不是完整官方 contrib wheel。
- ModelScope 下载入口独立派生为 `1.38.1+umi.download.1`，保留实际 snapshot 委托、异常、回调、常量及环境桥接，不再携带无关模型、训练和上传框架。
- 已核定的可选 Python 包、开发命令启动器和 CUDA 的 nvBLAS/cuFFTW 包装器不进入运行闭包。核心 cuBLAS、cuBLASLt、cuFFT、cuDNN 及实际模型算法保持。
- 插件仍拥有私有依赖和独立 worker，不借用宿主私有 numpy/Paddle 来缩小体积。需要兼容 CUDA 12.6 的 NVIDIA GPU 和驱动，不静默回退 CPU。
- 不下载、量化、修改或删减既有模型，不削减语言、精度或既有 GPU 架构。Paddle 大型原生库内部裁切受真实工具链限制，仍保留原库，不声称已完成内部重编。

最简运行包与对应源码、构建输入、来源材料和审计分开提供。运行包保留必要依赖、CA 证书、版权许可和源码取得指引，不包含私有 UI 解锁 DLL。

## 实际验证与边界

源码闭包更正后的正式候选 `dependency-trim-20261115-cuda-r4` 已与既有图像裁切本体组成全新候选，重新执行并通过真实 GPU 批量 OCR、PDF 两页、分层 PDF、JPEG XL 二维码、模型释放、未启动拒绝和无效 GPU 失败路径。实际结果见本轮审计 `cuda-production-consumers-r5/result.json`，不是将旧候选通过记录改写到新可执行文件。

- 模型与配置输入摘要保持。
- ModelScope 实际载荷逐文件匹配独立派生 wheel；被裁包、开发启动器及两个可选包装器没有残留。
- 首次预测后的动态模块取证确认观察到的 NVIDIA 包内库从当前候选加载，没有从外部回退加载已删除包装器。未观察到某个库不构成其无用的证明。
- ModelScope 原版与派生均通过隔离离线命中/未命中及参数委托测试，没有在线下载验收。旧 `MS_CACHE_HOME` 环境变量的上游路径类型错误在两者均存在，原失败单独保留，没有扩展修复范围。
- 最简分包及发布校验辅助文件的源码导出缺口已补齐，隔离导出源码的辅助工具导入测试通过。新候选的冻结源码和完整成员摘要已核对。逐文件比较发现仅 worker EXE 及其原生锁改变，因此另行执行了本段所述的新 GPU 验收，没有直接复用旧 EXE 的运行结果。构建时冻结的旧草稿保留当时状态，本稿另行记录后续验收事实。

E 盘 r3 分包已完成最终运行归档、独立源码归档及正式全新重装。重装核对 6,140 文件、3,985,147,709 逻辑字节；源码归档核对 320 文件、1,489,458,770 逻辑字节。来源材料实际包含派生 OpenCV 源码归档、原构建记录及匹配交付工具，不改写原 CUDA 冻结源码。主线程重算两个最终归档摘要、绑定回执，比较完整运行清单并核对实际重装 SOURCE.txt；原逐成员核验和全新重装结果复用，不冒充再次执行。入口为 `evidence/cuda-e-final-primary-review-r1.json`。

本轮只在私有执行字节未变范围复用 GPU r5，没有因 E 盘分包再跑 GPU。新取得的 NumPy 官方源码补充未插入这份冻结源码归档，现有来源及许可限制保持。2026-11-16 已与官方 Qt 本体 3.1.5、新 PaddleVL 3.1.4 从最终归档全新重装，逐文件摘要一致；实际 EXE、第二实例、回环注册接口及 Qt/QML/离线富预览通过。固定安装已完成，本插件实际版本为 3.0.6；用户数据原地保留且摘要一致，更新后未再次启动用户安装。本轮没有重跑 GPU，复用范围由 `combined-plugin-gpu-reuse-r1.json` 绑定。

不执行截图、HDR 或混屏测试，对应项目保持 **NOT_RUN**。本机 GPU 验收不代表所有设备或驱动矩阵，也不构成精度提升、模型质量升级或性能提升的声明。

宿主现有 PyMuPDF 官方 wheel 的 MuPDF 核心缺少可验证的确切对应源码绑定，相关公开分发门禁保持 **BLOCK**；本 CUDA 插件的独立状态不替代宿主门禁。
