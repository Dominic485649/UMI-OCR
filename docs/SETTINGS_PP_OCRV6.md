# PP-OCRv6 CUDA 设置说明

适用于独立 CUDA 插件 3.0.7 修复候选及其兼容宿主；公开可用版本以 Releases 为准。主程序、CUDA、PaddleVL 各自维护版本，不要求同版。Windows 10/11 x64、Python 3.13、随包 CUDA 12.9 私有运行库；CUDA 不可用时明确失败，不回退 CPU、oneDNN、ONNX 或 DirectML。

## 在哪里设置

- **识别后端／模型**：任一 OCR 功能页的“识别模型”下拉框，各 OCR 页共享选择。
- **模型文件、CUDA 设备、预处理线程、预热与清理**：全局设置中的插件／模型分组。
- **任务参数**：对应图片或普通文档页。HTTP 以能力 schema 默认值和本次 options 为准，不自动复制截图页的自定义参数。
- **界面语言不是识别语言**：PP-OCRv6_medium 使用统一多语言模型，当前 CUDA 插件没有语言包选择器。

GUI **不再提供“识别预设”**。`ocr.preset` 仅在旧 HTTP 输入兼容层接受，不由当前 CUDA `/get_options` 返回，也不是另一套模型默认值。

## OCR 选项

| 参数 | 当前默认值 | 作用与资源影响 |
| --- | --- | --- |
| 检测／识别模型 | `PP-OCRv6_medium` | 当前插件固定模型；机器参数仍保留，界面不重复绘制只有一个选项的下拉框。 |
| 文档方向分类 | 开启 | 校正横放／倒置文档，增加少量计算。 |
| 文档去扭曲 | 按任务自动 | 截图型图片任务关闭；批量图片和普通文档任务开启。可明确指定关闭或开启。 |
| 文本行方向 | 开启 | 校正单独旋转的文字行，增加计算及显存占用。 |
| 长边限制 | 4000 px | 640–8000 的整数；超出单次预算可分块处理。提高不等于无条件提高质量，须评估小字、分块边界和显存。 |
| 识别批量 | 6 | 1–64；较大批量可能提高吞吐，但增加显存与系统内存。 |
| 置信度阈值 | 0.45 | 0–1；提高可过滤误识别，也可能丢失低对比文字。 |

长边、识别批量、阈值和预处理线程等项可能需要开启“高级”才显示。参数来源为插件 `config.py`，以运行中能力查询为准；这些值不是本轮重新测得的质量／性能推荐。

## 硬件与生命周期

| 设置 | 当前默认值 | 边界 |
| --- | --- | --- |
| 推理加速 | CUDA 12.9 | CUDA 12.9 GA 对应 Windows 驱动 576.02；实际架构覆盖另行检查，MX250 不支持；RTX50 实机验收仍单列。 |
| CUDA 设备 | `gpu:0` | `gpu:N` 对应实际设备；运行时显存预算与设备有关。 |
| 预处理线程 | 逻辑核心少于 6 时用全部，否则减 4 | 控制解码和预处理，不代表 CPU 推理。 |
| 模型预热 | 首次使用时加载 | 立即／延迟预热均在主窗口首帧之后，不能把可用状态误当成已加载模型。 |
| 预热延迟 | 0 分钟 | 只用于延迟预热模式，范围 0–60 分钟。 |
| 自动清理 | 不自动清理 | 可选高内存占用或空闲策略；活动任务期间不清理。 |
| 空闲清理时间 | 30 分钟 | 5–120 分钟；下次使用仍须重新加载。 |

任务中改选模型或设备会等待已接纳任务安全收尾。托盘提供预热／清理入口；本轮未重新运行 GPU 推理性能矩阵，不把页面可用或历史结果当作模型运行通过。

## 旧 HTTP 预设兼容

旧请求可显式传 `speed`、`balanced`、`accuracy` 或 `custom`：前三项会在兼容边界展开并覆盖受管字段；要自行指定这些字段请使用 `custom` 或不传 `ocr.preset`。这些兼容项不是 GUI 选项，也不会恢复到查询 schema。

| 旧输入值 | 方向／去扭曲／文本行方向 | 长边 | 批量 | 阈值 |
| --- | --- | ---: | ---: | ---: |
| `speed` | 关／关／关 | 1600 | 16 | 0.60 |
| `balanced` | 开／按任务／开 | 2560 | 12 | 0.50 |
| `accuracy` | 开／按任务／开 | 4000 | 6 | 0.45 |
| `custom` 或不传 | 不由兼容层覆盖 | 按本次参数及 schema 默认值 | 同左 | 同左 |

接口详见[图片 OCR](http/api_ocr.md)、[普通文档 OCR](http/api_doc.md)。PaddleVL 的结构化文档接口及模型参数不是这张表的另一种预设，见[结构化文档](http/api_document.md)。

## 输入格式与未验收边界

宿主图片筛选包括 JPEG/JPE/JFIF、PNG、WebP、AVIF、JXL、JXR/WDP/HDP、BMP 和 TIFF。具体后端有各自的解码与预算路径，不能把宿主后缀列表当作每个插件／格式组合均已通过的证据。当前审查已把 CUDA 的 JXL/JXR 解码衔接及高位深转换列入后续定向修复／验证项。

截图白点和峰值设定仍保留。按照既定边界，本轮不执行屏幕捕获、HDR、混屏／多屏测试，也不要求用户补测；旧校准步骤仅为[历史材料](HISTORY.md)，不是新版本的通过记录或发布要求。
