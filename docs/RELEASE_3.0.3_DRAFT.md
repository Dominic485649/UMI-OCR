# Umi-OCR v3.0.3：合并修复本地候选（R2 待验收/待审）

> 本地候选 Release 草稿，不是发行完成公告。含最新修复的 R2 须重建并验收，再交用户审查。当前尚未创建 `v3.0.3` 公开标签或 GitHub Release；不提供虚构的 3.0.3 下载链接，不把旧候选改名为新版。

本版将 **3.0.2 的核心修复与最新修复合并为 3.0.3**，继续处理[批量文件追加后不继续识别的问题](https://github.com/Dominic485649/UMI-OCR/issues/1)，停用不安全的旧源码原地刷新工具，并修复从组合候选生成 CUDA overlay 时混用宿主/插件对应源码的问题。本次不升级识别引擎、模型或依赖。实现说明、自动化结果与完整人工操作验收分别记录，首轮 R1 的通过结果不直接套用到 R2。

实际 R2 程序和本稿须先交由用户审查，获得明确同意后才推送；公开发行还须通过相应门禁。用户的一般发布请求，以及对 HDR 功能正确的确认，不视为对本轮 R2 程序和文案的审查同意。

## 合并更新内容

- **运行中追加进入实际队列。** 批量文档在处理、暂停和保存收尾期间接收新增文件；批量图片 OCR 同样支持追加与续接，单段结束不再等同于整批结束。
- **等待队列可整理。** 文档列表支持拖拽排序和移出队列，真实执行顺序、文档数和页数预算同步调整。正在准备、处理或保存的文档受保护；移除记录不删除磁盘原件或识别结果。
- **导入与路径索引隔离。** 打开文件与拖入共用导入路径，支持文件夹及中文、空格路径。文件列表增删移动同步修正路径索引，清空、停止和关闭后的旧异步导入不再复活任务；加密件保留为待解密，其它正常件继续处理。
- **文档行操作与输出保护。** 右键提供打开原件、打开实际保存产物和单件重新 OCR。重新识别使用独立输出名，成功后才更新最近成功产物，失败或取消保留旧成功输出。这是实现范围，完整 GUI 流程仍须验收。
- **忽略区域与预览。** 修复右键绘制状态、数组更新通知、取消、反向拖动和边界裁剪。预览使用当前编辑区域，并以请求代次隔离跨文档的晚到响应。
- **输出与退出收尾。** 修复同名独立文本覆盖、不同参数任务混用、产物记录重复复制和主线程重复查盘。后台准备与保存采用独立有界调度，退出等待输出收尾；部分导入失败、取消解锁及暂停后的末尾结算不再误报全成功或触发系统后续动作。
- **配置折叠与枚举提交。** 分组折叠使用当前设置对象，保留原分类与折叠键；刷新枚举模型或程序化更新索引不写回配置，保留 lazy 预热策略，仅真实用户选择提交。包内回归应显式加载包内文件，不能借仓库源码掩盖旧包问题。
- **停用旧源码原地刷新工具。** `build/tools/refresh_candidate_source.py` 仅保留明确的停用提示，旧参数和强制选项不能启用刷新；不读取、修改或删除候选包，也不访问兄弟插件项目。新增安全回归约束文件系统和进程副作用。新候选须在新目录构建，不能单独替换冻结包的源码、运行载荷或来源记录。
- **隔离组合候选的 CUDA 对应源码。** 生成 CUDA overlay 时必须取插件自己的对应源码、版本、快照和 provenance，不再回退到宿主根目录，避免把宿主源码串入插件归档。缺少明确插件来源的旧组合候选应拒绝并要求重新装配，不自动猜源。此修复针对封装来源，不升级识别引擎、模型或依赖。

## 版本与安装范围

| 项目 | 3.0.3 准备范围 |
|---|---|
| 产品版本 | 主程序与公开 CUDA 插件同步为 3.0.3 |
| 平台 | Windows 10/11 x64 |
| 锁定环境 | Python 3.13.16，PySide6/Qt 6.11.2，CUDA 12.6；不升级依赖锁 |
| 推理后端 | 基础程序不含 OCR 推理后端；公开配套插件为 PP-OCRv6_medium CUDA |
| 模型 | 沿用既有离线输入；不改模型 URL、模型字节或量化精度，不下载新权重 |
| Host API | CUDA 插件保持 `>=2.7,<3.0`，产品版本变化不等于 API 主版本变化 |
| 公开资产 | 仅基础程序与 CUDA 插件，不含 CPU 或 PaddleOCR-VL 插件 |

本版候选就绪后，先完整解压基础包，再将匹配的 CUDA 插件完整解压到同一应用根目录，保留归档相对路径及插件独立的许可证、对应源码和来源材料。建议使用新目录，不覆盖正在运行的旧程序。

需要兼容 CUDA 12.6 的 NVIDIA 显卡与驱动，不需要另装 Python 或系统 CUDA Toolkit。CUDA 不可用时明确报错，不静默回退 CPU。`.tar.xz` 包含外层 xz 和内层 tar；若工具先输出 `.tar`，请继续解包直到根目录出现完整程序和 `Umi-OCR.exe`，不要仅复制启动器。

仍保留下列验收限制，未完成前不能写作完整人工清单通过：

- **原生 Explorer 与鼠标。** 外部文件/文件夹拖放、原生右键及拖拽手势、默认阅读器行为须实际验收。Qt 合成事件和路径分派观察不能替代 Windows 系统输入或外部阅读器验收。
- **GUI 单件重新 OCR 与旧产物保护。** 完整菜单流程、成功/失败/取消后的旧产物哈希保留须执行到底，不能只引用后端回归。历史合成整轮曾在菜单定位处超时，不把未执行部分当作已通过。
- **完整预览过滤与保存返回。** 须验证原生右键框选、当前区域在实际 OCR 中过滤文本、保存并返回文档列表的完整流程，不能仅验证区域坐标或单个 QML 状态。
- **HDR、混合屏与多屏。** 用户确认只证明其反馈的功能体验，不补全新包实测证据；混合 HDR/SDR、多显示器及完整人工视觉清单仍须独立记录，不继承旧版人工接受结论。
- **旧安装和用户数据。** 本稿不表示已迁移配置、切换旧安装或执行清理。验收通过后，旧版及无效构建缓存的清理仍由本项目流程在检查占用、备份和确认范围后执行，不访问兄弟项目，不删除模型或对应源码。
