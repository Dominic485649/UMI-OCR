# 两仓磁盘硬门槛与本轮回收记录

日期：2026-11-19。范围：`Umi-OCR` 与同目录 `Umi-OCR-Plugin`。此记录是本地执行和验收证据，不是公开发布许可。

## 容量口径

两仓根 `CLAUDE.md` 均记录：D 盘至少保留 **10 GiB**，两仓合计至多 **300 GiB**（1 GiB = 1,073,741,824 字节）。构建、测试、打包、重新安装和固定更新前按保守的峰值预算同时过两条线；写入时分阶段或按块监测。两仓可共享经平台、架构、Python ABI 和摘要核对的只读构建资源，最终安装闭包不能依赖另一仓目录。

[初测原始记录](../build/audit/gpu-compat-20261117-r1/space-floor-initial-census-console-r1.txt)按 NTFS 文件分配、压缩/稀疏文件及数据流核对；包括 Git、缓存、暂存、归档和固定安装。按卷与文件 ID 去重硬链接。未跟随 15 个重解析点，未发生普通文件统计错误，不将卷元数据或外部目标计入两仓。初测主仓 **286,424,703,613** 字节、插件仓 **180,250,182,780** 字节，合计 **466,674,886,393** 字节（约 **434.63 GiB**），超上限约 **134.63 GiB**。初测结束 D 盘可用 **5,244,891,136** 字节（约 **4.88 GiB**）。两个条件当时均不满足。

[两仓清理后重测](../build/audit/gpu-compat-20261117-r1/space-floor-after-build-cleanup-r1.json)：主仓 **217,220,543,955** 字节，插件仓 **88,127,071,356** 字节，合计 **305,347,615,311** 字节（**284.38 GiB**）；D 盘可用 **166,577,143,808** 字节。仍为 15 个重解析点未跟随、0 项读取错误，两条门槛均恢复。

开始新打包前，两份运行归档、VL 实测和定向夹具合计增长按 **12,145,196,099** 字节预算，峰值约 **295.69 GiB**；不预支 NTFS 或 XZ 压缩收益。新打包器在实际写入前检查 10 GiB 线和每归档已核对的增长预算，并[定向检查两条容量边界](../build/audit/gpu-compat-20261117-r1/stream-pack-tests-r3-stderr.txt)。

为留出最终重装及固定事务的峰值，打包期间另外回收[首批 CUDA 分包的 13 个二进制副本](../build/audit/gpu-compat-20261117-r1/space-floor-superseded-cuda-r1-result.json)与[首批 PaddleVL 分包的 6 个二进制副本](../build/audit/gpu-compat-20261117-r1/space-floor-superseded-vl-r1-result.json)，原分配分别为 **5,247,332,352** 和 **4,346,384,384** 字节。保留已逐成员验过的旧运行归档、原始构建/验收记录和新精简暂存；两组清理均未与当前打包共用输入。

[最终归档后的阶段账本](../build/audit/gpu-compat-20261117-r1/space-floor-after-exact-pack-budget-r1.json)用实测双仓基线、两批实际回收和两份实际归档分配计算占用上界 **301,437,351,195** 字节（含 128 MiB 小产物余量）。[重装及固定更新预检](../build/audit/gpu-compat-20261117-r1/space-floor-reinstall-and-fixed-budget-r1.json)：新增峰值分别为 **12,624,787,034** 和 **7,050,430,053** 字节；同时保留两阶段也满足双仓上限。重装或事务开始时重新检查 D 盘，不预支待退役旧载荷的回收空间。

## 本地交付终态

固定事务已提交，**228** 个程序文件更新或新增，**714** 个旧载荷文件退役，**3,665** 个保留文件 SHA-256 不变，未留事务旧载荷备份。两份新归档归位后只删除了 release 中超过保留范围的两份旧归档；[固定安装及归位核验](../build/audit/gpu-compat-20261117-r1/exact-local-delivery-final-r1.json)确认三组件和六份保留归档。
