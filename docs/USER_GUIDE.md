# 常用操作

安装与组件选择见[主 README](../README.md)。以下介绍当前行为，不用旧界面截图保证新界面外观一致。

## 图片 OCR

在截图 OCR 页粘贴、拖入图片，或在批量 OCR 页添加文件/目录。支持 JPEG/JPE/JFIF、PNG、WebP、AVIF、JXL、JXR/WDP/HDP、BMP、TIFF。损坏、缺少解码器或超过预算的输入会明确失败。

识别结果支持文字编辑、复制和多项选择；预览按原始四点多边形显示文本，滚轮缩放以鼠标所在图像位置为锚点。模型与 CUDA 设备统一在全局模型设置中选择。不要用提高边长或并发替代显存预算评估。

### 排版与忽略区域

排版解析可选择多栏/单栏、自然段/总是换行/合并，以及保留缩进等模式。忽略区域通过右键拖动矩形定义：只排除整个文字块完全落入区域的结果，不按单个字符切除。相关参数见 [PP-OCRv6 设置](SETTINGS_PP_OCRV6.md)。

## PDF 与结构化文档

普通文档识别支持 PDF、XPS、EPUB、MOBI、FB2、CBZ，按文件能力提取原文或执行 OCR，可导出可搜索 PDF。忽略区域可排除页眉页脚。图片 OCR 与 PDF 处理保留，不因最简分包而裁掉。

PaddleVL 完整文档解析通过 [HTTP 文档接口](http/api_document.md) 使用，输出 Markdown、结构化 JSON 和资源。其文档任务 UI 默认不显示。离线 Markdown 预览支持表格、公式、代码和图片；默认导出不重复附送 TXT，显式 HTTP TXT 请求仅为兼容层。

## 模型生命周期

默认首次使用才加载；也可设置启动后立即或延迟预热。任务运行时可选择下一模型，待当前已接纳任务安全收尾后切换。托盘可预热/清理，自动清理策略包括关闭、系统内存高占用和空闲超时；任务运行时不清理。

PaddleVL 模型支持[手动导入与下载](MODEL_DOWNLOADS.md)。文件下载到当前已安装插件根目录的 `model/`，不会移动外部模型。

## 界面、托盘与二维码

- 全局设置可切换语言、字体、大小、浅/深色及跟随系统主题。
- 标签栏可置顶窗口、锁定标签页，防止误关。
- 托盘单击触发截图、双击打开窗口，右键打开设置、预热/清理或退出。
- 二维码页可读取多码或生成码图，支持常见 QR 与一维码协议。

快捷键和截图能力保留，但本轮不主动验证桌面捕获、HDR 或混屏/多屏；这些场景保持 NOT_RUN。
