## 本次变化与组件边界

- 本体采用明确标识的 OpenCV 图像子集，保留 core、imgproc、imgcodecs 和 Python 绑定，保留 JPEG SIMD。它从固定上游源码构建，不是完整官方 contrib，也不是简单替换为 headless wheel。
- imagecodecs 保留实际 JPEG XL/XR 消费者所需原生模块、公共辅助代码及原始许可。AVIF、WebP 等图像能力由对应的实际消费者闭包保留，不以单个包的模块删减推断整机格式支持变化。
- 上游输入锁与派生载荷身份分开记录。派生版本、实际成员摘要、RECORD、来源回执和第三方组件说明互相绑定，不沿用官方完整 wheel 的身份冒充未修改发行版。
- 本次 Qt/PySide/shiboken6 复用锁定的官方 6.11.2 wheel，在全新候选内重新计算 QML、插件和 PE 依赖闭包，保留文件字节不变。四发行版输入、裁切策略、QML 输入和实际保留载荷须分别绑定，拒绝复用不匹配的旧清单。此前原生 Qt/扩展 Mojo 工作保留为独立来源与诊断材料，不混入本次官方二进制验收。官方 Qt DLL 内的静态 FFmpeg 不能通过文件级裁切移除，本次不宣称这项内部裁切完成。
- 运行包只提供本体，不内含 OCR 推理插件。CUDA 与 PaddleVL 保持各自私有依赖和独立安装边界，不通过借用宿主私有数值库或删减模型能力缩小插件。
