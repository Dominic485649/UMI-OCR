# PP-OCRv6 CUDA 插件 3.0.7 审阅草稿

> 本轮 GPU 兼容修复候选，尚未公开发布。首批文件回带已由精确闭包锁纠正；新精简 CUDA 候选通过真实 OCR 定向验收，运行归档重新生成后已逐成员核对，完整对应源码按独立核验回执复用。首批归档仍暂停交付，不以旧重装记录代替最终验收。

## 修复内容

- 在精简版 CUDA 3.0.6 基线上接入官方 Paddle GPU 3.3.1 的 Windows x64 / CPython 3.13 / CUDA 12.9 构建及匹配的 NVIDIA 私有闭包；PaddleOCR 3.7.0、PaddleX 3.7.2、原有模型和参数能力保持。
- 本轮已对下载候选的两份核心库实际检查，确认具有 sm75/80/86/89/120 cubin，无 PTX；不是只凭 CUDA 版本号推断。最终包仍须另行核对准确载荷及运行记录。
- 对 MX250 等未覆盖设备，在模型加载前明确提示不支持；此轮不增加 sm61 实际识别或 CPU 回退。保留严格标量自检和同步，区分架构、CUDA 执行和结果错误，提供可定位的诊断及日志路径。
- 保留 OpenCV core/imgproc/imgcodecs 派生构件、ModelScope 下载子集、可选包/包装器裁切、Stored-ZIP 和独立私有依赖，不回退完整依赖大包。新版 NVIDIA 的 PEP 639 许可路径原样保留。

## 独立版本与兼容性

CUDA 插件独立升为 **3.0.7**，Host API 仍为 **>=2.7,<3.0**；本轮本体复用 **3.1.5**，PaddleVL 因其自身 Paddle 闭包同步变化独立升为 **3.1.5**，不是要求组件同版。

程序自带运行库，不要求安装系统 CUDA Toolkit。实际支持还取决于已包含的 GPU 代码及驱动；不能把“算力至少 7.5”理解为所有更高算力都已支持。CUDA 12.9 GA 对应 Windows 驱动 576.02；PaddleVL 的 llama 运行库要求独立保留。

## 验收与限制

本轮在 RTX 4060 Laptop / 驱动 621.14 完成基础 GPU 运算、包内批量图片、两页 PDF／可搜索 PDF、模型释放和错误 GPU 路径；从最终归档重装的三组件组合通过实际 EXE、回环接口、CLI 和正常退出。固定安装已更新为 CUDA 3.0.7，既有用户配置原地保留。[本地归档](../release/Umi-OCR-Plugin_v3.0.7_Windows_x64_CUDA.tar.xz) · [统一审阅及实际回执](GPU_COMPAT_20261118_REVIEW.md)。**RTX50 实机仍为 NOT_RUN，不以 4060 结果代替 5060。** 截图捕获、HDR、混屏未运行。

新 GPU 支持会增加部分原生库体积；不以删模型、减语言/精度或降低架构覆盖制造精简收益。最终运行包与对应源码/原始审计分离，保持来源、摘要和许可指引。

## 公开发布边界

本地运行归档为 2,507,677,320 字节，超过 GitHub 单附件 2 GiB。CUDA 12.9 的再分发适用性不继承旧 CUDA 12.6 快照的通过；NVIDIA/AGPL、确切原生来源及既有其它公开门禁分别保留。当前没有此版本程序和文案的公开发布批准，不推 main、打发行标签或上传 Release。
