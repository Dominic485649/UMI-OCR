# PaddleVL 插件 3.1.5 审阅草稿

> 本轮与精简成果整合的 GPU 兼容修复候选，尚未公开发布。新精简 PaddleVL 已通过文件锁、Stored-ZIP、插件定向测试与真实模型工作流；最终归档已重装核验并更新固定安装，不以 3.1.4 或首批候选的历史通过代替。[本地归档](../release/Umi-OCR-Plugin_v3.1.5_Windows_x64_PaddleVL.tar.xz) · [统一审阅与实际回执](GPU_COMPAT_20261118_REVIEW.md)。

## 修复内容

- 保留 3.1.4 的文档解析、文字定位、标题/表格重组、ModelScope 下载子集、派生 OpenCV、科学计算子集与 Stored-ZIP 精简成果。
- 私有 Paddle GPU 闭包与 CUDA 插件同步迁至审定 cu129 组合，以补齐 Paddle 核心库对 sm120 的代码覆盖；仅更新 CUDA 图片插件不能解决 VL worker 自身的 Paddle 自检问题。
- 共用同一份仅依赖标准库的 worker 兼容检查逻辑，保留独立安装边界；对不支持的显卡、执行异常和错误结果给出准确诊断，不回退 CPU。
- 按已核验摘要复用原精简 llama.cpp 运行库及对应来源，不因本条 Paddle 错误重编 llama。模型、GGUF、mmproj、量化精度及既有 HTTP 启用/监听/鉴权设置不变。

## 独立版本

本插件因自身 GPU 闭包变化升为 **3.1.5**，Host API 保持 **>=2.9,<3.0**；本体复用 **3.1.5**、CUDA 插件独立为 **3.0.7**。版本相同不代替实际兼容性验收。

Paddle cu129 与 llama CUDA 13.x 是隔离进程中的不同运行库；两者各自的架构及驱动条件必须满足，不能凭显卡名称或驱动显示的最高 CUDA 版本保证可用。

## 验收及交付边界

在本机 RTX 4060 Laptop 上，**新精简候选**已通过真实 Spotting 和复杂文档回环 HTTP、共享模型服务同 PID、非空官方标题 KMeans、表格、公式、图片及 JSON／Markdown／TXT 导出。实际观察了 Paddle 与 llama 的 GPU 模块路径并核对摘要；模型和运行锁未变。没有用首批额外依赖候选的结果代替本次验收。归档重装与固定安装状态见[统一审阅及本轮回执](GPU_COMPAT_20261118_REVIEW.md)。**本机 RTX 4060 不能替代 RTX 5060 实机验收，RTX50 仍为 NOT_RUN**；MX250 不属于本轮实际识别兼容目标。

截图捕获、HDR、混屏继续 NOT_RUN。运行归档与完整对应源码/审计独立提供，不包含私有 UI 解锁 DLL 或私有实现源码。

## 公开门禁

本地运行归档为 3,041,557,572 字节，超过 GitHub 单附件 2 GiB。源材料、NVIDIA 再分发适用性、AGPL/私有组合及既有其它公开门禁仍独立保留。本地计划批准不等于当次程序及文案公开审查同意；目前不推 main、打发行标签或公开发布。
