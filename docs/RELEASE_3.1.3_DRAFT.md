# Umi-OCR 3.1.3 · 模型直链下载与最简运行分发

## 组件与兼容性

| 组件 | 本次提供版本 | 变动 |
| --- | --- | --- |
| 主程序 | 3.1.3 | 模型下载 UI/宿主连接、运行分包与文档整理 |
| CUDA 插件 | 3.0.5 | 执行载荷不变，仅提供最简重新分包，不重编译、不量化 |
| PaddleVL 插件 | 3.1.3 | 固定官方模型资源与下载入口，独立对应源码交付 |

主程序 Host API 仍为 2.9；CUDA 范围 `>=2.7,<3.0`，PaddleVL 范围 `>=2.9,<3.0`。版本独立，不能用同号代替兼容性验证。Python、Qt、两插件的模型精度和现有推理依赖不升级。

## 更新内容

- PaddleVL 主 GGUF、视觉投影 GGUF、PP-DocLayoutV3 三个模型路径行，在文件选择按钮左侧新增“下载”。使用固定官方 HTTPS 直链、revision、大小和 SHA-256，不自动切换量化档。
- 模型写入用户实际安装的 `UmiOCR-data/plugins/win32_PaddleOCRVL_1_6/model/`，不是开发仓库、系统缓存或固定的开发模型目录。
- 后台显示进度，支持取消，完整校验后才回填路径。已有外部模型仍可手动导入，不搬迁、不覆盖同名冲突；软件启动时不自动下载或预热模型。
- 移出额外附送的顶层开发源码树、源码 ZIP 和内部审计，运行依赖、必要 CA、版权与许可原文继续保留。Qt/Chromium 声明收集不再把界面中的 `notice` 源码、脚本和图片误当法律文件。
- 完整对应源码独立、免费提供，与实际运行载荷按摘要绑定。PaddleVL 的源码交付包含适配器、实际 MPL 来源与原生对应源码，不把只有适配器的小包当作全部来源。
- README 中英日入口、文档导航、模型获取和使用说明更新，保留原贡献署名和历史验收记录。

## 下载与安装

- 主程序运行包及其对应源码放在主程序发行页。
- 插件发行页同时提供 PaddleVL 3.1.3 与 **CUDA 3.0.5 最简重新分包**，以及各自完整对应源码。既有 CUDA 3.0.5 发行、标签和旧附件不覆盖；本次分包的名称、大小与摘要以本页新清单为准，不代表 CUDA 引擎升版。
- 主程序完整解压到可写目录，再把所需插件完整解压到同一主程序根目录。更新前正常退出，不覆盖运行中的软件；保留已有配置、日志、任务资源和用户模型。
- PaddleVL 超过单附件大小限制，以 `.tar.xz.001`、`.002` 等原始字节分卷提供。下载本页全部分卷、`archive-chunks.json`、`Restore-ReleaseArchive.ps1`，使用本体自带便携 Python 校验还原完整 `.tar.xz` 后再解压；单卷不能直接安装。分卷不改变压缩内容。
- 普通使用无需下载源码。需要源码时，通过同一发行页的 `CorrespondingSource.tar.xz` 附件获取；使用本页校验和核对，不依赖泛化仓库首页。

## 验收与边界

- 复用并逐文件重新核对同一 3.1.3 执行闭包的真实 Main.qml、浅/深色 × 中/英/日 × 100%/150% 共 12 组界面记录，以及实际 EXE、托盘、第二实例 CLI 和正常退出记录。本轮不把复用说成全部重新执行。
- 真实固定官方 `inference.json` 的完整 HTTPS/TLS 传输和 SHA-256 校验已执行；大 GGUF、视觉投影及版面参数的完整网络下载为 **NOT_RUN**。
- 既有模型实际执行 CUDA OCR、PaddleVL OCR、版面检测文档链与 TXT 导出；模型前后摘要一致。这是合成 PNG 的代表性 GPU 场景，不是本轮 PDF 选页/整篇或全部格式矩阵重跑。
- 截图捕获、HDR、混屏/多屏继续 **NOT_RUN**，不要求补做；非 Windows x64、全部显卡/驱动和用户原始文档未验收。
- PaddleVL 文档解析默认通过 HTTP API 使用，默认界面不展示文档任务页；模型下载不改变 HTTP 启用、监听或鉴权配置。
- **原生闭包保留例外：**PaddleVL 现有完整性清单要求 `resources/llama.cpp/source/` 中约 106.4 MiB 原始来源材料存在，删除会被判定为运行时损坏。本轮不改这个已验收契约，原件保留，完整对应源码另行提供；不宣称运行包中完全没有源文件。
