# Umi-OCR 3.0.0 发布审查

主程序与 CUDA 插件使用标签 `v3.0.0`，Python 保持 3.13.16 共用。用户已经审阅 README 并授权审查与验收完成后直接正式发布。本报告记录当前代码与构建的验证；最终归档、安装和公开链接的证据随 Release 提供，不将旧候选证据作为本次结论。

## 文档链接检查

已提取当前源码、元数据与维护文档中的 HTTP/HTTPS 链接并做去重可达性检查。HTTP 200 只说明有响应，不代表网页内容、锚点或下载资产正确。

已修正本项目导航、CUDA 仓库下载分工、失效的星标入口、当前 API 示例和翻译链接。确认失效的译者个人链接移除超链接但保留姓名与贡献。历史记录、上游资产和来源证据保留其真实归属。

仍可能存在访问限制、网络超时或历史失效地址，不能宣称全仓所有外部网站正常。尤其是 Weblate 多个个人页与 Stack Overflow 可能受限，上游旧截图可能无法直接获取。普通 OCR/文档接口依旧没有身份认证，文档明确说明局域网开放的边界；本机命令接口另加来源限制。

新插件仓库和 `v3.0.0` 下载地址将于正式发布后复核。最终链接结果与资产哈希写入发布报告，不伪造缺失数据。
